# 04 — Internationalization

## v1 decision

- **UI language**: Uzbek, **Latin script**, only.
- **Content language**: all questions/options/explanations authored in Uzbek (Latin).
- **Russian and Cyrillic**: deferred to v2, but the data model and UI are built so they can
  be added without a rewrite.

## UI strings

- All user-facing strings go through a **single string catalog**, not inline literals — even
  though there is one language in v1. This is what makes adding Russian later cheap.
- Suggested approach: a typed `uz` dictionary in the frontend (e.g. `src/i18n/uz.ts`) keyed
  by string id, accessed via a small `t(key)` helper. A `lang` value on the profile selects
  the catalog; v1 always resolves to `uz`.
- Backend user-facing messages (validation/error `detail` strings) are likewise written in
  Uzbek. Keep them centralised so they can be translated later.

## Content language on questions

- `Question.language` (and any translated child rows) carry an explicit language code
  (`"uz"` in v1).
- For v2 bilingual content, the model options are: (a) a `translations` table keyed by
  `(question_id, language)` holding prompt/options/explanations, or (b) parallel question
  rows linked by a `content_group_id`. **Decision deferred to v2**; v1 stores a flat `uz`
  row but keeps the `language` field so migration is additive.
- Media (images, animations) is generally **language-neutral** and shared across
  translations; any text baked into an image is the exception and must be re-authored per
  language.

## Formatting and copy conventions (Uzbek)

- Use Uzbek Latin orthography consistently (o', g', sh, ch, ng).
- Exam terminology: **YHQ** (Yo'l Harakati Qoidalari), **haydovchilik guvohnomasi**
  (licence), **nazariy imtihon** (theory exam), **chorraha** (intersection), **yo'l belgisi**
  (road sign), **to'xtash/to'xtab turish** (stopping/parking).
- Result copy: **O'tdingiz** (pass) / **Yiqildingiz** (fail), **Imtihonga tayyorlik**
  (exam readiness), **Xatolar** (mistakes).

## Non-goals (v1)

- No language switcher in the UI (single language).
- No auto-translation of content; Russian content, when added, is authored/reviewed by a
  human (LLM drafts allowed but must be verified — see [00-overview.md](00-overview.md)).
